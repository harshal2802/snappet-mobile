Wardrobe — your private AI stylist

A new Snappet mini-app (module id wardrobe, proposed category Lifestyle). Local-first: SwiftData + on-device Vision / Apple Intelligence — no account, no backend, photos never leave the phone. Optional iCloud sync via CloudKit mirroring. MVP scope = capture → AI tagging → digital closet → outfit generation → style coach → collage → backup.

wardrobe rose — proposed module accent (light #C13A6F / dark #E86B99) brand coral — the single primary CTA per surface perfFresh — "good match / synced" signals perfModerate — "rarely worn" nudges azure — weather chip only (WeatherKit)
In this MVP: ① capture (camera / Photos import) + background removal (VisionKit lift-subject) · ② on-device AI tagging (category · color · pattern · style · material · season) · ③ closet browse / search / filter / edit / archive · ④ “For You” suggested-outfits feed (daily, on-device, pick-to-wear) + custom generator (occasion + weather + free text, owned items only) · ⑤ style coach Q&A (Foundation Models) · ⑥ flat-lay collage board · ⑦ outfit history + wear log · ⑧ .wpack export/import (SwiftData models kept CloudKit-compatible from day one so Snappet-level iCloud backup/restore can be switched on later with no migration).
Deliberately later: live CloudKit sync toggle · internet Inspiration search (wireframed below as FUTURE) · Closet Camera live-scan · packing assistant · analytics dashboard · wishlist · widgets/App Intents · Android port.
Flow A

Entry & the Digital Closet

Wardrobe joins the App Library as a normal Snappet module (one-line registry add). The closet is a bright, catalog-like grid — search, filter chips, wear-count pills, and an amber nudge on rarely-worn pieces. First-run sells the privacy story.

Flow D

“For You” feed, custom generation, the flat-lay board & history

The middle tab is a For You feed: every morning the composer pre-builds a handful of outfits from today’s weather + wear history (rarely-worn pieces get rotated in) and the user just picks one. “Style me” opens the custom generator for a specific occasion. Each board piece has a swap affordance; “Wear today” logs every piece’s wear count.

FUTURE · Inspiration search. Not in this build — but the MVP’s tag schema (category/color/style/material) is exactly what own-first matching needs, and the wishlist grows out of “missing pieces”.

Build shape (for the PDD prompt): pure keystone WardrobeEngine layer — OutfitComposer (rules: occasion→formality, weather→layer/season, color harmony from tag data), WearStats (cost-per-wear, rarely-worn), WardrobePackCodec (.wpack) — all unit-testable with no device. Platform edges in Services/: VisionKit subject-lift, Vision classification + Foundation Models tagger (with a deterministic heuristic fallback when Apple Intelligence is unavailable), WeatherKit, CloudKit mirror. SwiftData models: WardrobeItem, WearEvent, Outfit, OutfitSlot. Sim/UITest path ships with a seeded fixture closet (no Photos dependency — same trick as Kilter fixtures).
