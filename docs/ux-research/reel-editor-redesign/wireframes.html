Reel editor, grown up

The reel becomes the screen. Today's ReelView is a settings-page-shaped List: a "Preview reel" button where the video should be, three stacked control sections, and clip rows labelled with raw stitched-timeline offsets ("52:33") and a meaningless "intensity 13%". The redesign borrows the grammar of Edits / CapCut / Instagram: an auto-playing preview canvas fills the screen, Export is THE action (top right), tools compress to one chip row, and the highlight list becomes a filmstrip timeline under the player. Same ViewModel, same pipeline — presentation only.

The reel IS the screen. The preview auto-builds and loops (muted) on open — the "Preview reel" button dies. Export is the one prominent action (top-right, Edits-style); the title carries the honest "8 clips · 0:28". Aspect + HR-overlay live in ONE tool row — the HR chip shows the actual glass scorebug on the preview (the same tile the export burns), replacing the footer sentence about it. ↻ regenerates (confirm-gated, unchanged); ☰ opens the edit list (screen 3). The filmstrip is the highlight list: duration badges, a peak-effort tint bar per frame, 📌 pins, tap → clip sheet (screen 2). Scrubbing the player highlights the clip under the playhead.

Tap a frame → the clip sheet, with a real trimmer. Named for what it is — "Clip 2 of 8 · 10s" with the PEAK-BPM pill — never the raw stitched-timeline offset ("52:33") or "intensity 13%". NEW: per-clip trim handles — the auto-cut window can be dragged anywhere inside the clip's source video (min 1s; the engine's clipStartWithin hook was built for exactly this). The trim feeds the same plan the preview and export consume, so what you drag is what ships. Pin / Remove move here from hidden swipe gestures (still available in the edit list); removed clips collapse into the "+N removed" ghost frame, restored from the edit list.

☰ → the edit list, re-skinned. The power-user surface keeps everything the old List did — drag-reorder, pin, remove, restore, the honest pick-shortfall note — but rows lead with Clip n · duration · kind and the PEAK badge. Presented as a sheet over the editor so the mental model stays "one screen with tools", not a settings page.

Kept (same ViewModel, same pipeline)

  • All of ReelViewModel: generate/regenerate (confirm gate), pin/remove/restore/reorder, format WYSIWYG (makeComposition(renderAspect:)), overlay toggle, export → payoff screen, Post to Clips.
  • Recovery states (empty/denied/limited/error/exportFailed) — untouched.
  • Exported payoff screen (`ExportedView`) — already video-first; untouched.

New presentation

  • Auto-built looping preview fills the screen; scrubber + "0:11 / 0:28" chip; play/pause on tap.
  • Export = the prominent top-right pill (was "Share reel" mid-list).
  • One tool row: aspect chips · HR chip (live glass scorebug on the preview — the burn, previewed) · ↻ · ☰.
  • Filmstrip timeline = the highlight list: duration badge + peak-tint bar + 📌; tap → clip sheet; "+N removed" ghost restores.
  • Clips named "Clip n · 10s" + PEAK pill.

Deleted

  • The "Preview reel" button + preview-on-demand.
  • Raw stitched-timeline offsets ("52:33") and "intensity 13%" as row copy.
  • The two instructional footers ("Format frames the exported reel…", "Swipe ▸ to remove…").
  • The mid-list Share/Regenerate button pair.
