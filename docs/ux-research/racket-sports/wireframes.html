Racket sports — matches & drills

A new Racket discipline in the Quick Session pager, covering table tennis, badminton, tennis, squash, pickleball and padel. Each sport is a real type with its own scoring rules. Each one runs in two modes: a Match (opponent, format, a score per game or set, an auto-derived result) or a Drill (timed blocks with made/attempted counts). Clips claim the game they were filmed in. Heart rate is back-filled from Apple Health, so a Fitbit works as well as an Apple Watch.

Flow A

Start: pick the sport, then Match or Drill

The add page gets a seventh type tile, Racket. Tapping it opens the sport picker. The sport you pick sets the scoring rules and the Health workout type, and Match / Drill sets the page. A match asks only who you're playing and the format. Everything else is optional, and recent opponents and events are one tap.

Flow B

Match page: one game at a time

The match page puts the match score at the top. Each game you've played is a chip (won green, lost red, 🎥 if it has clips), and the current game owns the screen. You can start a game timer, or skip it and just log the score. Record game films the current game, and stopping the recording asks for the score. The score sheet checks the sport's rules and works out who won.

Flow C

Tennis & padel: sets of games, with tiebreaks

Tennis and padel use the same page, scored one set at a time instead of one game at a time (you chose a score per game or set, not every point). A set at 6–6 shows the tiebreak stepper. A deciding super tiebreak (to 10) is an option in the format. Padel defaults to doubles.

Flow D

Drill page: practice, measured

A drill is a named practice block from a sport-specific list (serve practice, multiball forehand, footwork, smash practice…), or one you name yourself. Each block logs a duration and, optionally, made / tried, giving an accuracy %. "Longest rally" is an option for rally drills. Blocks are compared to last time, as strength sets are.

Flow E

After: HR back-filled from Health, per-game Clips

When the Fitbit (or any wearable) syncs to Apple Health, Snappet reads the heart-rate samples inside the session window and adds them to the session, so every game gets its own HR. It retries on the next foreground until HR arrives. The Fitbit's own overlapping workout is not turned into a duplicate Clips post, and its HR goes into this session.

Scoring rules (pure, unit-tested)

One small rules engine per sport family

SportUnit scoredRuleDefault formatHealth type
Table tennisgameto 11, win by 2best of 5 (3/7)Table Tennis
Badmintongameto 21, win by 2, capped at 30best of 3Badminton
Squashgameto 11 (PAR), win by 2best of 5Squash
Pickleballgameto 11, win by 2 (15/21 options)best of 3Pickleball
Tennisset (games)to 6, win by 2; 7–6 tiebreak at 6–6; super tiebreak to 10best of 3 setsTennis
Padelset (games)as tennis; doubles by defaultbest of 3 setsTennis*
  • Never blocking: a score that breaks the rules gets an amber warning but still saves, because a real match can have odd scoring (a retirement, a house rule). The result is worked out from the score whatever happens.
  • Retire / walkover is in the ✎ Match details menu. It ends the match with a note instead of a fake score.
  • *HealthKit has no padel type, so an Apple Watch records padel as Tennis and the Snappet session keeps the real sport. Badminton, squash, pickleball, table tennis and tennis all have native types.
  • Not in v1: point-by-point scoring and serve/rally stats, a live scoreboard mode, opponent profiles beyond a name with a head-to-head record, and Android.
