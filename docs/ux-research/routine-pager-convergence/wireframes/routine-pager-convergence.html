What changes (+ new)

  • + Routine plays through the same pager — swipe between its exercises instead of a locked script.
  • + Rail chips carry the plan count (2/4); the segment bar & steppers are seeded from the target + last time.
  • + Expandable: “1 extra set” goes beyond the plan; Add appends an off-plan exercise; History › shows vs-plan deltas.

Where this lives in code. The fork is one line — WorkoutTrackerModule.swift:220: session.routineID == nil → FreeformPlayerView (pager), else WorkoutPlayerView (guided). The convergence routes routine sessions into FreeformPlayerView too, seeding its pages/steppers from each SessionExercise’s target (the pager already logs every discipline — the keystone parity comment in WorkoutPlayerView.disciplineInputs confirms both sides share reps×weight, the grade rail, the stopwatch, run legs).

Open question for you: keep the guided player available anywhere (e.g. a “focus mode” toggle for a strict, no-swipe run), or fully replace it? That decision shapes whether WorkoutPlayerView stays or is retired.
