Ideation · not a spec · 2026-10-12

Activity progress: past clips + a dashboard for each activity

For any exercise or climb in a session, see every photo and video you've ever tagged to it, each with that set's numbers. Then give every activity its own dashboard where the chart and the clips are linked.

01The data is already there

No schema change. Each clip already knows its session and its exercise, and the exercise's exerciseId stays the same across sessions. One new pure function does the join.

SessionMediasessionID + assignedExerciseID + set index + offsetSec
→
WorkoutSession.exercisesSessionExercise.id → exerciseId (catalog) or adhoc-* + displayName
→
ActivityMediaIndex new · pureGroups history + media by activity. Each clip is stamped with set stats + HR. Unit-tested, no simulator
→
Past clips · Compare · Dashboard · Progress reelAll read the same index
✅ Uses the same matching rule as QuickSessionPager.lastSessionSets (catalog id, or ad-hoc by name). ⚠️ Clips in the General bucket and sessions from before set-assignment existed won't appear unless they get re-tagged.

02Where you open it

The same sheet opens from four places. The live pager matters most: you can check your last attempt before you start.

🏋️
Live pager

A ▶ 14 past clips chip on each exercise page. Opens a sheet and the session keeps running.

📋
Session detail

The same chip on each exercise row in a finished session.

🎞️
Clips feed

"More from Bench Press" in a post's long-press menu (from prompt 174).

📚
Library / dashboard

A filmstrip on the activity dashboard (section 05).

Defaults to the first and latest clips, and you can swap in any two. Playback is synced, with slow-mo for a form check. "Ghost" is an opt-in overlay mode for later.

04Four ways to see progress

Ordered from cheapest to most ambitious.

🗂️
1 · Timeline

Each clip is labeled with its set and HR. Uses existing data only.

⇆
2 · Then vs Now

Two clips side by side, synced. Good for form and smoothness.

★
3 · PR moments

The clip from each record (first 80 kg, first V5 send) marked automatically.

✦
4 · Progress reel

One tap: oldest → newest montage with burned captions ("Jan 50 kg → Oct 75 kg"). Reuses ReelView, posts as ✦ REEL.
