Library redesign

Today the Library is a catalog: ~870 bundled strength moves, your custom exercises, saved timed protocols, and four climb/run templates — always A–Z. What you actually do (the climbs, runs, holds and lifts you log in sessions) isn't in it, and there's no way to sort by what you use. This redesign makes the Library yours first, keeps the catalog for discovery, and gives every activity one page that ties together its progress, clips and how-to.

04Decisions for you

Green is what I'd pick.

1 · Layout

AOne list, yours on top
BYours | Explore tabs (screens above)
CHub of shelves

2 · What makes two climbs "the same"

AName only (what the dashboards do since last week)
BName + gym when named; grade + gym + wall + colour when unnamed — so "V4 yellow, Cave wall" is a climb too. + the set window (user, 2026-10-14): gyms reset every 3–4 weeks, so the same name at the same gym after a gap of more than 4 weeks is a NEW climb ("set 14 Sep"). Logs inside the window stay one climb so a multi-session project isn't split. Window adjustable in Settings.
CThe full re-log key (type · scale · grade · name · gym · wall · colour) — a regrade would split it

3 · Where pins, hides, renames and saved-not-done items live

AA small new LibraryEntry record per activity (in backup); everything else still derived from history
BSettings-style flags only (no saved-not-done climbs/routes)

4 · Other sources in Yours

AGym Tracker sessions only for now
BAlso Kilter board climbs (badge) — Apple Watch runs later
CKilter + Apple Watch runs now

5 · Default sort

AMost used (sessions in the last 90 days, then all-time)
BRecently done

05Suggested order

One prompt = one PR each, wireframe-approved first.

L1Yours + sort
  • Pure LibraryCatalog: your activities from history (incl. climbs/runs), usage stats
  • Yours | Explore, sort menu remembered per discipline
  • Unified climb identity (decision 2)
L2Activity page
  • Progress · Clips · About tabs (dashboard + detail merged)
  • Log it now · Add to routine
  • Explore "DONE n×" badges
L3Pin · Rename · Merge · Hide
  • LibraryEntry model + backup
  • History-safe rename/merge (rewrites session names, undoable)
  • Look-alike suggestions
L4Create + pickers
  • ＋ for timed / climb / run route / other
  • Quick Session, routine and timed pickers use the Library
  • Kilter climbs in Yours (decision 4)
