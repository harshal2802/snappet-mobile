Quick Session — redesigned

Real-looking wireframes for the climb-first / exercise-first Quick Session. Every attempt logs underneath a named, typed, graded climb (or a named timed exercise) instead of as a flat row. Derived from a 38-agent deep-research + design pass and mapped onto the real Snappet code. Read the full rationale in README.md.

Flow 1

Climbing — add a climb, then log timed & untimed attempts under it

Tap Climbing → name a route (type · grade · gym) → log every go beneath it. A timed attempt opens a full-cover FOCUS timer with a giant Stop. Live stats (sends · hardest · pyramid) build as you climb. This is the fix for “you can’t group three tries on the same V4 project.”

Why this works

• One form, then one-tap logging. The expensive type/name/grade step happens once per climb; every later go is a single gesture.

• ~1:1 code reuse. The climb-parent + attempts shape already exists as KilterLogEntry; stats as KilterSessionStats; the timer as StopwatchView. They just need wiring into the freeform flow.

• The one net-new model: route types (TR/lead/sport) + YDS/French scales. Isolate it in its own phase.

• Honest states everywhere. No-HR, untimed, first-ever, 2-hour, and Reduce-Motion variants are designed, not afterthoughts.
